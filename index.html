License

Our projects use the Reciprocal Ethical AI License (REAL) 1.0. It's source-available, not OSI-approved, so read it before you depend on the code.

  • Use it freely. Run, modify, and share the code for ordinary software.
  • Train on it, open the model. Models trained on REAL code must release their weights, training scripts, and data under the same terms, including models served over a network.
  • Ethical limits. No mass surveillance, lethal autonomous weapons, unlawful discrimination, or unmonitored critical infrastructure.
