Assembly · pre-release

arm-tools

A language server, linter, and formatter for AArch64 assembly on Apple silicon and Linux. Errors as you type, in clang's words.

Docs →Source →

; armtool: fn _sum(x0: ptr<i32>, x1: u64) -> i64
_sum:
    mov     x2, #0
1: cbz     x1, 2f
    ldrsw   x3, [x0], #4
    add     x2, x2, x3
    sub     x1, x1, #1
    b       1b
2: mov     x0, x2
    ret

License tooling · 0.1.1

real-check

Checks a repository and every dependency for compatibility with REAL 1.0, from license file to SPDX headers. Runs in CI, exits non-zero when something's off.

Source →

$ real-check check .            # repository and dependencies
$ real-check repo .             # license file, manifests, SPDX headers
$ real-check classify "MIT OR GPL-3.0-only"
$ real-check check . --format json --strict
